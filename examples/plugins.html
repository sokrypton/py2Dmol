Plugins

A plugin is a piece of JavaScript that draws things that are not residues, using three primitives: ctx.line, ctx.dot and ctx.tri. Points are in the file's own coordinates, so a plugin turns, zooms and clips with the structure. Each example prints its plugin and the code that hands it a payload; the payloads are computed here from the structure being drawn. See docs/PLUGINS.md for the full contract.

Renderer Style

1. Lines: a bounding box

Twelve edges around the alpha carbons of ubiquitin. bounds() tells the viewer how far the plugin reaches, so the opening view fits the box as well as the protein.

2. Balls and lines: a binding pocket

  
Trypsin with benzamidine (3PTB). A ball at the ligand's centre, a wire sphere at the chosen
  radius, and a line from the ligand to every alpha carbon inside it. The radius and the
  contacts are plugin options: changing one redraws without sending the payload again.

3. Triangles: principal axes

  
Triosephosphate isomerase (1TIM). The three principal axes of the alpha carbons, each as long
  as two standard deviations along it, with arrowheads built from triangles. Triangles are
  opaque, flat-shaded and lit by their own normal. The GPU tube has no shape for a triangle,
  so in tube style on the GPU this viewer draws with the 2D tube instead.
